**Topic:** Rollback vs Rollforward



**Concepts Learned:**

* Rollback
* Rollforward
* Database Compatibility
* Schema Migration Risks



**Key Insights:**

* Rollback returns to a previous version.
* Rollforward introduces a corrected future version.
* Database changes can make rollback difficult.



**Systems Engineering Principle:**

Recovery strategies must account for dependencies, not just application code.



**Progression:**

Feature Flags → Rollback / Rollforward
