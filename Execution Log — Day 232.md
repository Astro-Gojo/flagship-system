**Concepts Learned:**

* Infrastructure as Code
* Infrastructure Automation
* Configuration Drift
* Desired State
* Infrastructure Version Control
* Reproducibility



**Key Insights:**

* Infrastructure can be managed similarly to application code.
* Version control makes infrastructure changes traceable.
* Automation reduces repetitive manual work and configuration errors.
* IaC becomes increasingly valuable as infrastructure scales.
* IaC can support disaster recovery by making environments reproducible.



**Systems Engineering Principle:**

If infrastructure matters, make it reproducible and version-controlled.



**Progression:**

CI/CD → Infrastructure as Code → Automated Infrastructure Management
